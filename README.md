# Landing Page ขายน้ำผึ้ง (LSM21367 กลางภาค 008)

- `index.html` หน้าแลนดิ้งเพจ ดึงสินค้าจาก Google Sheet มีตะกร้าและฟอร์มสั่งซื้อ
- `label.html` ใบหยิบสินค้า, ใบแพ็คสินค้า, จ่าหน้าพัสดุ (สร้างจากข้อมูลคำสั่งซื้อ)
- `products.csv` ข้อมูลสินค้าตัวอย่าง (นำเข้า Google Sheet)
- `images/` โฟลเดอร์เก็บรูปสินค้า (ต้องสร้างและใส่รูปเอง)
